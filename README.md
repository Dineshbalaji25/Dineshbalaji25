## ⚡ Production Engineering Case Studies

### 🛡️ 1. PostgreSQL MultiXactId Wraparound Recovery
- **Scenario**: Production catalog queries crashed with `MultiXactId has not been created yet` on high-concurrency order updates without RDS superuser access.
- **Solution**: Queried `pg_class.relminmxid` to map transaction boundaries, executed targeted `VACUUM FREEZE` with tuned memory parameters (`maintenance_work_mem = 1GB`), and refactored row-locking to optimistic concurrency.

### 🌐 2. Meta Conversions API (CAPI) Network Leak Resolution
- **Scenario**: Event Match Quality dropped to 4.2 due to Docker bridge IPs (`172.17.0.2`) leaking into CAPI payloads and worker crashes on deleted items.
- **Solution**: Reconfigured Nginx reverse-proxy with `real_ip` directives, safe `X-Forwarded-For` parsing, and defensive JSON serialization with immutable product snapshots.

### 📊 3. Cross-Platform Attribution Ledger
- **Scenario**: 35% conversion tracking discrepancy between Meta Ads Manager (180 signups) and GA4 (118 signups) vs PostgreSQL ground truth (134 signups).
- **Solution**: Engineered a persistent first-party database ledger storing UTM touchpoints and click IDs (`fbclid`/`gclid`), mitigating iOS Safari 24-hour cookie wipes.
